# LPの設計室 — 簡易LP構成作成デモ

地域サービスなどの情報を入力し、LPの9セクションをブラウザー内で組み立てるデモです。初期表示には架空の地域密着型ハウスクリーニングの入力例と完成プレビューを用意しています。

## 起動

Node.js 22.12以降を想定しています。

```powershell
npm install
npm run dev
```

本番用の静的ファイルは `npm run build` で `dist/` に出力します。Viteの `base: './'` により、販売HPのサブディレクトリにも配置できます。公開先のURLとリンクは配置時に確認してください。

## 操作

1. 初期表示の完成例を見る。スマートフォンでは「サンプルの完成例を見る」から結果へ移動できます。
2. 入力例を自分のサービス情報に変更して「この内容でLP構成を作成」を押す。
3. FV、悩み、共感、解決策、サービス紹介、強み、利用の流れ、FAQ、CTAをページ形式で確認する。
4. 各セクションの「文章を編集」で見出しや本文を修正し、「文章をまとめてコピー」で原稿を取り出す。
5. 「入力例に戻す」でサンプルと完成例を復元する。

必須項目は業種、サービス名、提供内容、ターゲット、悩み、強みです。悩み・強み・利用手順は1行に1件で入力します。強みと手順は `見出し｜具体的な説明` の形式に対応します。

## 生成の仕組み

`src/lib/generate.ts` がターゲット、悩み、強み、提供内容の言葉から「時間」「不安の解消」「品質」「地域・利用しやすさ」などの訴求軸を選びます。セクションごとに見出しと文章構造を変え、同じ入力なら同じ結果になります。入力されていない料金、期間、実績、保証、問い合わせ先は作りません。

FAQの回答は入力した内容だけを表示します。問い合わせ先URLがない場合、生成LPのボタンは見た目だけのプレビューであることを明示します。URLは `http://` または `https://` のものだけリンクとして使います。

入力や生成内容は送信・保存しません。編集した原稿は再生成すると置き換わるため、必要な文章はコピーしてください。公開前には記載内容を確認してください。

## 販売HPの相談導線

実際の問い合わせURLが決まったら `.env.example` を参考に `.env.local` へ `VITE_SALES_CONTACT_URL` を設定します。値がない場合、アプリ末尾の制作相談ボタンは表示されません。この値は公開用ビルドに含まれるため、秘密情報を設定しないでください。

## 構成

- `src/App.tsx`: 画面状態、生成、コピー、サンプル復元
- `src/components/`: 共通ボタン・入力部品、入力パネル、LP完成プレビュー
- `src/lib/generate.ts`: 訴求軸の判定と9セクションの生成
- `src/data/sample.ts`: 架空のハウスクリーニング事業の入力例
- `src/styles.css`: 画面とプレビュー、スマートフォン向けのCSS
- `PLAN.md`: 要件・設計判断・第1版の範囲

LPの構成・コピー設計には `D:/Claudecode/06_LP作成` と `D:/Claudecode/10_LPスキルパック_v1.2` の考え方を必要な範囲で参考にしました。既存の文章、コード、画像は転用していません。
